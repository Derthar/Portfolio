Добрый день
В данном репозитории представлены примеры проектов, над которыми я работал

Основные направления:
- автоматизация тестирования;
- разработка небольших утилит;
- работа с GUI;
- изучение архитектуры приложений.

1. Backuper_GUI

Описание:
Небольшая утилита которая с заданной периодичностью копирует указанные файлы, тем самым создавая "бекапы". Была написана по просьбе друга для автоматизации резервного копирования файлов

2. Django

Описание:
Учебный проект по Django

3. Page-object-Project

Описание:
Учебный проект по автотестированию с использованием Python, Pytest и Selenium. Иcпользовался паттерн Page Objects.
Данный проект использовался как основа для изучения и дальнейшего применения автотестов в рабочей деятельности.
Рабочие автотесты не представлены в открытом доступе.

4. Phonebook

Описание:
Тестовое задание от одной из компаний.
Консольный телефонный справочник, который хранит данные в текстовом файле.
Поддерживает добавление, изменение и удаление записей

5. Read_logs

Описание:
Небольшая программа, создана с помощью Python + PyQt6 для того, чтобы облегчить мое управление локальными тестовыми стендами на моем первом рабочем месте.
Рабочие стенды там устанавливались локально на компьютер и запускались через диспетчер задач.
Возможности:
- запуск и остановка стендов;
- быстрый доступ к логам;
- открытие последних версий логов подсистем;
- очистка папок с логами.
