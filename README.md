5. Read_logs

Описание:
Небольшая программа, создана с помощью Python + PyQt6 для того, чтобы облегчить мое управление локальными тестовыми стендами на моем первым рабочем месте.
Рабочие стенды там устанавливались локально на компьютер и запускались через диспетчер задач. Все логи хранились в различных папках, причем каждый день файлы обновлялись.
Данная программа поддерживает 4 стенда(можно легко увеличить это количество) и позволяет в простом GUI включать/отключать стенды, читать последние версии логов всех подсистем стенда а также производить очистку папок с логами.
